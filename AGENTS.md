# AGENTS.md — cozmars

## Project

ESP-IDF v6.0.2 workspace with no root app: the app logic lives in reusable components under `components/`, and every runnable app is a standalone IDF project in `examples/`.

## Build & Flash

```sh
# an example (each example is its own IDF project)
idf.py -C examples/<name> build
idf.py -C examples/<name> -p /dev/ttyUSB0 flash monitor
```

`IDF_PATH` must be set.

## Layout & key files

- `components/cozmars` — core robot hardware: display (ST7789/LovyanGFX), I2C buses, codec (ES8311/ES7210), sub-processor control (`sub_ctl`: motors, servos, WLED), camera (GC0308/DVP)
  - `include/` public headers, `src/` sources
  - `example.c` — reference hardware init order (documentation only, not in the build)
  - `sdkconfig.defaults.recommend` — recommended board config; copy to an example as `sdkconfig.defaults`
- `components/wifi_mngr` — Wi-Fi STA manager with hotspot provisioning fallback (web page embedded from `web/wifi_prov.html`)
- `components/util` — small helpers (`util.h`, `server_util.h`) and shared scripts (`scripts/embed_web_files.cmake`, `minify_gzip.py`)
- `examples/` — self-contained IDF projects reusing `../components` via `EXTRA_COMPONENT_DIRS`: `camera_stream`, `sub_board_control`, `record_and_playback`; each has a brief README
- `sdkconfig` — auto-generated by `idf.py menuconfig`; **do not hand-edit**
- `../cozmars-sub/sub_i2c_msg` — I2C message protocol shared with the ESP32-C3 co-processor firmware (sibling repo)

## Hardware

- **SoC:** ESP32-S3R8 (8MB PSRAM)
- **Flash:** 16MB external flash
- **Display:** 1.14" ST7789 LCD (SPI)
- **Camera:** OV3660 or GC0308
- **Audio:** ES8311 (DAC + amp out) + ES7210 (ADC, 2x mic in) — 16 kHz / 16-bit
- **Sensors:** 6-axis gyro, TOF proximity sensor, cliff IR — via sub board
- **Co-processor:** ESP32-C3 ("sub board") communicating via I2C; drives motors, servos, WLED, reads sensors

## Rules

- Never edit `sdkconfig` directly — use `idf.py menuconfig`.
- Never commit `build/`, `sdkconfig`, `managed_components/`, or compiled artifacts (`.o`, `.elf`, `.bin`, `.map`).
- Add new source files to the owning component's `CMakeLists.txt` via `idf_component_register(SRCS ...)`; public headers go in the component's `include/`.
- Embedded web assets: add the HTML to the component's web folder and register it with `embed_web_files(<list_var> WEB_EMBED)` from `components/util/scripts/embed_web_files.cmake` (see `wifi_mngr/CMakeLists.txt` for usage).
- Don't build the project unless explicitly asked to.
- When adding new features or examples, refer to official examples at `{IDF_PATH}/examples` for reference patterns.
